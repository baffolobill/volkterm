# VolkTerm releases

Release builds of VolkTerm, a macOS terminal on libghostty. Apple Silicon, macOS 14 or later.

- **Homebrew:** `brew tap baffolobill/tap && brew trust baffolobill/tap && brew install --cask volkterm`
- **Direct download:** the `.dmg` from [Releases](../../releases); after dragging the app to /Applications run
  `xattr -dr com.apple.quarantine /Applications/volkterm.app` once.

Installed copies check this repository for updates.
